# Scientific Programming

Implementation of the Richardson iterative method
for solving systems of linear equations Ax = b.

## Project structure

- Matrix.h / Matrix.cpp - Matrix class
- Solver.h / Solver.cpp - Iterative solver
- main.cpp - Main program
- build.sh - Build script

## Requirements

- C++17 compiler
- Bash

## Build and run

chmod +x build.sh
./build.sh
